Build a FAIRSCAPE Data Package

A data package bundles your files with metadata describing what they are, who made them, and how they were made — so other people (and AI tools) can find, trust and reuse them.

Data + Metadata = FAIRSCAPE Data Package

Where are you starting from?

Just starting? Try an example — open a finished package or run a small workflow to see how it works.

Under the hood a FAIRSCAPE Data Package is an RO-Crate — the open standard for packaging research data with its metadata — so any RO-Crate tool can read it.
